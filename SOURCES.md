# Sources and optional integrations

These public projects informed the selection of complementary audit stages. Bounty Pilot contains original workflow text and Python helpers, not a redistribution or merged copy of their skill files.

- Pashov skills — https://github.com/pashov/skills — preparation, audit passes, fuzzing.
- Trail of Bits skills — https://github.com/trailofbits/skills — delta/variant analysis, verification, property tests.
- 0xSimao AI — https://github.com/0xsimao/0xsimao-ai — accounting-focused review.
- QuillShield — https://github.com/quillai-network/quillshield_skills — semantic guards and invariant analysis.
- Sanbir — https://github.com/sanbir/solidity-auditor-skills — complementary EVM checks; overlaps with Pashov.

No specific upstream version is bundled or claimed to have executed. Runtime integrations must record a reviewed commit and retain upstream licensing. Bounty Pilot's MIT license applies only to original content in this repository.
