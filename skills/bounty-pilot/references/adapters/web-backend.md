# Python / TypeScript / web backend adapter

Start from app routes, auth/session middleware, permission sources, background workers, DB schema/migrations, RPC clients and external services. Follow full input-to-output lifecycle including async queues and webhooks. Prioritize IDOR, authorization scope mismatch, stale cache permissions, nonce/signature intent binding, JS Number safe-integer loss, Decimal/bigint/canonicalization, duplicate payments/claims and time-of-check/time-of-use. Trace retry/idempotency and what remains durable on partial failure. Use pytest/hypothesis or Jest/Vitest/fast-check native harnesses with transaction fixtures and authenticated cross-user negative controls. Do not use a live external service as a load-test target. Separate reported REST success from confirmed chain/DB effects.
